# 校缘聚（CampusGather）桌游/剧本杀组局平台

这是第 1 组软件工程课程“软件设计报告与实验”原型实现，依据 `第1组+软件设计作业.pdf` 中的架构、模块、接口与数据库设计完成。

## 运行

```bash
npm start
```

打开：

```text
http://localhost:3000
```

如需重置演示数据：

```bash
$env:RESET_DATA="1"; npm start
```

## 原型边界

当前实现不接入真实微信 AppID、学校统一身份认证和线上推送服务；相关能力已通过模块和接口预留。项目统一使用 JSON 文件持久化，运行数据保存在 `data/*.json`，种子数据由 `src/database/seed.js` 初始化。密码使用加盐哈希保存，登录态使用随机会话 token，服务端仅保存 token 哈希和过期时间。
