# 校缘聚（CampusGather）桌游/剧本杀组局平台

校缘聚（CampusGather）是第 1 组软件工程课程项目实现版本，面向校园桌游、剧本杀等线下活动场景，提供组局发布、报名审核、场地预约、活动互评、投诉处理、信用记录和后台管理等功能。

项目采用 Node.js 后端、原生前端页面和 JSON 文件持久化实现，可直接在本地启动运行。最终版本补齐了期末汇报后待完善的登录注册、安全会话、互评、账号封禁、游戏库上下架、推荐排序、标签筛选、头像上传、组局分页和大规模自动化测试等内容。

## 功能概览

| 模块 | 已实现能力 |
|---|---|
| 用户与认证 | 昵称密码登录、学生注册、退出登录、安全会话、修改密码、实名认证申请与审核 |
| 个人中心 | 资料维护、兴趣标签、预设头像、本地头像上传、信用记录和通知查看 |
| 组局大厅 | 组局浏览、详情展开收起、分页、关键词筛选、类型筛选、标签筛选、热门/近期排序 |
| 组局流程 | 发布组局、直接加入、审核制申请、发起人审核、成员退出、取消组局 |
| 活动结束 | 组局开始后从大厅隐藏，发起人可标记完成或未组局成功 |
| 活动互评 | finished 组局成员互评，限制自评、重复评价和非成员评价，并按权限展示评价结果 |
| 投诉与信用 | 学生提交投诉，管理员处理投诉，投诉和互评可影响信用分并生成信用记录 |
| 游戏库管理 | 管理员新增、编辑、上架、下架游戏；普通用户只能查看上架游戏 |
| 场地管理 | 场地维护、场地预约审核、时间冲突检测、场地变更通知 |
| 管理后台 | 实名认证审核、账号封禁与解封、投诉处理、统计面板、管理员操作日志 |
| 测试 | 260 项自动化测试，覆盖接口、权限、状态流转、安全会话和 JSON 数据层 |

## 快速启动

安装依赖：

```bash
npm install
```

启动项目：

```bash
npm start
```

浏览器访问：

```text
http://localhost:3000
```

如需重置演示数据，可在 PowerShell 中执行：

```powershell
$env:RESET_DATA="1"; npm start
```

## 数据与实现说明

项目统一使用 JSON 文件作为本地持久化方案，运行数据保存在 `data/*.json`，默认演示数据由 `src/database/seed.js` 初始化。`data/` 目录用于本地运行，不作为固定提交数据；如需恢复默认演示环境，请使用 `RESET_DATA` 重置。

密码使用加盐哈希保存，登录态使用随机会话 token，服务端仅保存 token 哈希、过期时间和撤销状态。账号封禁后旧 token 会失效，退出登录后 token 也会被撤销。

当前版本面向课程提交和本地演示，不直接接入真实微信 AppID、学校统一身份认证、校园场地系统和线上推送服务；相关业务通过本地账号、管理员审核、场地管理和站内通知保留完整流程，后续可继续对接真实外部系统。
