# 评测演示数据

所有初始账号默认密码均为 `abc123456`。如果本机已经运行过项目，需要重置 JSON 数据后才能看到最新种子数据：

```powershell
$env:RESET_DATA="1"; npm start
```

重置后再次普通启动即可：

```powershell
npm start
```
